# Portfolio Website

A responsive personal portfolio website built with HTML, CSS, and JavaScript. It showcases skills, education, projects, and contact information in a clean single-page layout.

## Features

- Responsive design for desktop and mobile devices
- About, skills, projects, education and contact sections
- Mobile navigation menu using JavaScript
- Smooth scrolling between page sections

## Tech Stack

- HTML5
- CSS3
- JavaScript
